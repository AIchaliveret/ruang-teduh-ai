---

## Apa Itu Ruang Teduh?

Ruang Teduh adalah platform **SaaS SCM (Supply Chain Management) untuk Bio Healthy Space**.

Kami menggabungkan:
1.  **Ruangan Bio Sehat** yang nyata di Jakarta
2.  **Sensor 6-in-1 Multispektral Infrared** berbasis ESP32
3.  **Loker Fisik** untuk penyimpanan barang yang terpantau
4.  **Dashboard SCM** untuk memantau semua data secara real-time
5.  **Tiang Tangan Otomatis** (V3) untuk memilih dan memindahkan barang berdasarkan warna / kondisi

Prinsip kami: **UUD — Ujung-Ujungnya Duit.**
Kami pemilik platform. Mitra bayar untuk menempel, bukan sebaliknya.

## Peta Upgrade: V1 -> V2 -> V3

### V1 — SEKARANG — FONDASI [SUDAH JALAN]
Untuk: Hack2Skill / HackGlobal / Hack Stack

- Sensor 6-in-1 Multispektral Infrared
- ESP32 sebagai otak
- Loker fisik
- Dashboard SCM dasar: Suhu, Kelembaban, Kualitas Udara, Status Loker

**Output:** Data bisa DILIHAT.

### V2 — UPGRADE MODULAR — PLUG & PLAY
Inspirasi: Dashboard Modular ala Mahmoud BI

- Dashboard Modular: KPI di atas bisa ganti-ganti tanpa coding ulang
- Grafik bisa tambah sensor baru (misal CO2) langsung muncul
- Tabel SCM bisa tambah loker: 20 -> 100 loker, tinggal colok langsung terdeteksi
- Prinsip Plug & Play seperti Lego

**Output:** Sistem bisa DITAMBAH tanpa bongkar.

### V3 — NASA SPACE GUARDIAN — OTONOM
Kick Off: 18 November

- Sensor Infrared bisa bedakan warna: Hijau = Sehat, Kuning / Coklat / Hitam = Bahaya / Busuk / Stress
- Tiang seperti tangan / lengan robot: Kalau warna bahaya, tangan gerak otomatis pindahkan barang ke kotak karantina
- Dari hanya MELIHAT -> jadi MEMILIH + MEMINDAHKAN sendiri
- Aplikasi Bumi: Ruang Teduh. Aplikasi Luar Angkasa: Sampel tanaman / mineral Space Guardian.

**Output:** Sistem BERTINDAK sendiri.
